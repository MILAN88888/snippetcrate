Easily manage and execute custom PHP and JavaScript code snippets in WordPress with the Snippet Master plugin.

== Description ==

Snippet Master is a 100% free and open-source plugin designed to help you add, manage, and run custom code snippets on your WordPress site without editing theme or plugin files.

Features:

* Add PHP and JavaScript snippets from a clean React-based admin screen.
* A built-in Monaco code editor with syntax highlighting.
* Live syntax checking as you type — PHP is validated on the server and JavaScript in your browser — so snippets with errors cannot be saved.
* Choose where each snippet runs: PHP globally or in the header/footer; JavaScript in the header or footer.
* Activate, deactivate, search, filter, and bulk-delete snippets.
* Safe execution: a PHP snippet that errors is caught and automatically deactivated so it can never take your site down.
